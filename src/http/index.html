Escalations, policy & autonomy

Structured edits, validated with the same checks the daemon boots with; the previous config is kept as config.toml.bak. Changes apply on the next daemon restart.

Escalation chain — {"project": null, "steps": [{"contact": "*", "ack_timeout_minutes": 60, "repeat_interval_minutes": 20}]}; set "project" to a project name for its override (empty steps remove it).

Policy bounds — any of auto_approve, always_ask, command_allowlist, forbidden_paths (a provided list replaces that list).

Autonomy — {"project": "...", "env": "...", "target": "...", "autonomy": "observe|suggest|act_on_known|auto"} (omit env/target for higher levels; "auto" also needs "confirm_auto": true).
